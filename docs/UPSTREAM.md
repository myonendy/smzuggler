# Upstream patches

Follow [smzuggler's upstream workflow](../CONTRIBUTING.md#upstream-patches)
and the preserved [Outsider contribution policy](upstream-CONTRIBUTING.md).
Build topic branches from current upstream/main and validate with QuickJS
before opening a PR. Keep smzuggler-only changes out of upstream patches.

Add one row per PR when submitted. Status is draft, open, merged, rejected or
withdrawn; record the upstream merge commit and the smzuggler commit carrying
the patch until it lands.
