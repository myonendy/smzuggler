# Decisions, one file each

`DEC-<card ID>.md`, starting with `## DEC-<card ID> — <title>`: context, decision, why, the
rejected alternative. Only for choices a later agent could not recover from the code (a spec
section 2 rule, a file/save/digest format, a deliberate deviation from the spec). A card
that names `DEC-…` gets that entry in its context pack. Older entries may still live in
`docs/DECISIONS.md`; nobody appends there any more (AGENTS.md section 5).
